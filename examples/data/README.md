# DUTMed demo data

`dutmed-demo.jsonl` contains three unmodified records selected from DUTMed's
`data/症状.json`. They are bundled so a fresh TraceGraph checkout can demonstrate
document retrieval and graph relations without another repository or generated
test content.

DUTMed is distributed under the Apache License 2.0. Its license is preserved in
`DUTMED-LICENSE.txt`. The records are provided for software demonstration and
learning only; they are not medical advice.
