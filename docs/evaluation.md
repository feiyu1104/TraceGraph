# 检索评测指南

## 当前数据原则

应用运行和演示只读取 `../DUTMed/data/症状.json`，不使用自造疾病记录。项目不会把自动生成的问题和答案包装成“真实质量”报告。

## 如何准备可信评测集

1. 从 DUTMed 疾病记录中抽样，保留原始疾病名和字段位置。
2. 由人工编写真实问法，不直接复制字段标题。
3. 由另一位标注者确认相关文档与章节，形成 gold evidence。
4. 分别运行关键词、图和混合检索，比较 Evidence Recall@1/3/5。
5. 单独记录急症升级、证据不足、冲突和越界问题的预期状态。

Evidence Recall@k 的定义是：前 k 个结果命中的相关 Chunk 数量，除以该问题全部人工标注相关 Chunk 的数量。

## 为什么不直接自动生成成绩

从同一条 DUTMed 记录生成问题，再用该记录作为答案，会造成数据泄漏，只能证明程序连通，不能证明系统理解了真实用户问题。当前项目因此只交付评测程序，不附带这种合成医疗成绩。

DUTMed 本身也不能替代临床审核。任何医疗质量结论都必须注明数据版本、抽样方法、标注规范和审核者。
